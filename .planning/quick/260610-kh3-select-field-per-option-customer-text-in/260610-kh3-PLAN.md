<objective>
Add a per-OPTION "customer types text" capability to the existing Select config-field type. An admin flags an individual option (e.g. "Your name") so that, on the PDP, choosing that option reveals a required free-text input. The typed text becomes part of the order's `computedSummary` so it flows to bag → admin order detail → production board → invoice for free — same Select field type, NO new field type, NO DB migration.

Purpose: Customers can personalise a chosen option (type their name / custom phrase) while predefined options stay click-only. Per-option flags live in `product_config_fields.configJson` exactly like the existing per-option price/sku/imageUrl/weight overrides.

Output: schema flags `customInput?`/`customMaxLength?` on Select options, an admin toggle, a PDP input gated by the flag, summary wiring, and server-authoritative validation at EVERY order-creation path (checkout/POS/WhatsApp).
</objective>
