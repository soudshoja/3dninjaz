# Quick Task 260810-q0m — Evolution API attribution on /admin/settings

## Why

Evolution API (the WhatsApp gateway behind order notifications) is **not MIT**. Its
`LICENSE` is **Apache-2.0 plus additional conditions**. GitHub reports the repo license
as `NOASSERTION` / "Other" for this reason. Clause 1b:

> **Usage Notification Requirement**: If Evolution API is used as part of any project,
> including closed-source systems (e.g., proprietary software), the user is required to
> display a clear notification within the system that Evolution API is being utilized.
> This notification should be visible to system administrators and accessible from the
> system's documentation or settings page. Failure to comply with this requirement may
> result in the necessity for a commercial license, as determined by the producer.

3D Ninjaz is a closed-source system that uses Evolution API v2.3.7 (`/home/ninjaz/evolution-api`)
for order WhatsApp notifications. Before this change the string "Evolution API" appeared
only in source-code comments (`src/components/admin/whatsapp-connect-panel.tsx` JSDoc) —
never rendered to an administrator. That does not satisfy 1b.

Clause 1a (LOGO / copyright in Evolution's own frontend components) does not apply — the
Evolution Manager console is not exposed or rebranded by this app.

## Scope

Single-file, presentational, admin-only. No storefront change, no schema change, no
behaviour change to WhatsApp sending.

## Tasks

### T1 — Render attribution below the WhatsApp panel

- **files**: `src/app/(admin)/admin/settings/page.tsx`
- **action**: Add a small muted `<p>` immediately after `<WhatsappConnectPanel />`, inside
  the existing `mt-8 max-w-2xl space-y-6` stack. Text: "WhatsApp notifications powered by
  Evolution API (Apache-2.0)", with "Evolution API" linking to
  `https://github.com/evolution-foundation/evolution-api` (`target="_blank"`,
  `rel="noopener noreferrer"`). Add a code comment naming the licence clause so a future
  cleanup pass does not delete it as decorative copy.
- **verify**: `npx tsc --noEmit` exits 0; notice sits on the admin settings page, which is
  already `requireAdmin()`-gated and `robots: noindex`.
- **done**: Administrators see the notice on `/admin/settings`; storefront untouched.
