    - First await is `requireAdmin()`. Then:
      1. Validate every line server-side (configurable lines validate against `getPosConfigFields(productId)`; free-text validates name + unitPrice ≥ 0; stocked validates variantId belongs to productId AND is in stock unless override).
      2. Compute subtotal = sum(quantity × resolved unitPrice per line).
      3. If `couponCode` → call existing coupon validator (`validateCoupon(code, subtotal)` from `src/actions/coupons.ts` / `src/lib/coupons.ts`); on success → compute discountAmount.
      4. Compute shipping: if `shippingOverride` set → use it; else `getShippingRate(state, subtotal - discount)`.
      5. Total = subtotal - discount + shipping.
      6. Generate orderId via `crypto.randomUUID()`. orderNumber via `formatOrderNumber(...)`.
      7. Insert one `orders` row: `sourceType='manual'`, `status='pending'`, `paymentMethod=null` (per D-21 — set later on customer choice), `userId=session.user.id`, snapshot customer fields, totals.
      8. For each line: insert one `order_items` row. For free-text lines: `productId='manual'`, `variantId='manual'`, `productName=line.name`, `productSlug=null`, `productImage=null`, `variantLabel=null`, `unitPrice=line.unitPrice`, `lineTotal=line.unitPrice * line.quantity`, `configurationData=null`. For stocked lines: snapshot real `productName`, `productSlug`, `productImage`, `variantLabel`, real `productId`/`variantId`, override-aware `unitPrice`. For configurable lines: real `productId`/`variantId` (or `variantId='manual'` if no variant axis), `configurationData` LONGTEXT JSON-stringified, override-aware unitPrice.
      9. If coupon valid → call `redeemCoupon(couponId)` atomic UPDATE (Phase 5 05-03 pattern); on coupon exhausted → roll back the order insert (transaction).
      10. Wrap steps 7-9 in `db.transaction(async (tx) => {...})` so coupon redemption failure rolls back the order.

    - On success: `revalidatePath('/admin/orders')` + `revalidatePath('/admin/pos')`.
