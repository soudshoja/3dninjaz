<objective>
Give the admin a way to configure a `keycapseq` field: the letter constraints (maxSlots, allowedChars, uppercase, profanity) plus a multi-select of which of the 34 catalog icons that field's icon slots may offer (its `allowedIconIds`, mirroring `allowedColorIds`, D-09). This threads the new fieldType through the server-side config validator and the admin field-modal.

Purpose: Until the admin can pick allowed icons, the storefront `+ Icon` affordance stays hidden (empty allowedIconIds → graceful degrade). This plan makes the field configurable end-to-end on the admin side.
Output: `pickSchemaByFieldType` keycapseq case + a new `IconPickerDialog` + a `KeycapSeqConfigForm` wired into `config-field-modal.tsx`.
</objective>
