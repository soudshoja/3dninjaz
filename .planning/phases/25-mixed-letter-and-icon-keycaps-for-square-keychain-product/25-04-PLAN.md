<objective>
Add the third keychain production group: icon slots print as a fixed white shell + baked accent parts, which does NOT match the letter Base/Clicker/Letter colour grouping, so they batch by icon id (D-11). A mixed order still emits the existing BASE + CLICKER+LETTER letter batches — but their per-unit count must become the LETTER-slot count (not total slots, not `name.length`) — plus one icon-print entry per icon slot. Add the `iconDone` tick action and extend assembly readiness.

Purpose: Without this, a mixed order's icons are unprintable on the board (no batch) and the letter batches over/under-count (Pitfall 1). This is the one genuinely new production mechanism in the phase.
Output: KeychainIconBatch grouping + markKeychainIconPrinted + Icons segment UI, all square-only (D-01), regression-safe for all-letter stores.
</objective>
