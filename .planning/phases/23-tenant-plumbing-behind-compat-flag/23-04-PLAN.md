<objective>
Build the two pieces that make the multi-tenant request path real and safe: the in-process registry cache (`resolveDomain(host) → Tenant | null`) and the `getTenantContext()` resolver that binds Host → tenant → `{ tenant, db }`. This is the tenant-isolation trust boundary the whole platform depends on, and it carries requirement TEN-03: an unrecognized Host hard-fails and NEVER falls back to an existing tenant.

Purpose: `ProxyPreserveHost On` forwards whatever the client sent, and the shared cPanel box has default/catch-all vhosts, so the app is the last line of defense and must treat Host as untrusted input (PITFALLS.md Pitfall 4). A default-to-Tenant-#1 fallback turns a config typo into a cross-tenant data leak — the worst possible failure (ARCHITECTURE.md anti-pattern 2). Under `TENANT_MODE=single` (the deployed default) the resolver ignores Host and synthesizes one tenant from `DATABASE_URL` — byte-for-byte today's behavior.

Output: `src/lib/tenant/registry.ts` + `src/lib/tenant/context.ts` + co-located vitest tests.
</objective>

```typescript
// ARCHITECTURE.md reference shape (Phase 23 scope: { tenant, db } only — auth is Phase 24)
import "server-only";
import { cache } from "react";
import { headers } from "next/headers";
import { notFound } from "next/navigation";
import { resolveDomain } from "./registry";
import { getTenantDb } from "./pool-manager";

export const getTenantContext = cache(async () => {
  const h = await headers();
  const host = (h.get("host") ?? "").toLowerCase().replace(/:\d+$/, "");
  const tenant = resolveDomain(host);           // sync once cache is warm
  if (!tenant) notFound();                       // NEVER fall back to a default tenant
  if (tenant.status === "suspended") throw new TenantSuspendedError(tenant.id); // → 503
  return { tenant, db: getTenantDb(tenant) };
});
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → app (Host header) | `ProxyPreserveHost On` forwards arbitrary/spoofable Host values; the app is the last line of defense (untrusted input) |
| registry cache → tenant identity | The in-process domain→tenant map decides which DB every downstream query touches |
| unauthenticated request → tenant resolution | Public paths resolve tenant before any auth; a leak here precedes any session check |
